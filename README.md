# Harmonic Shadow

Локальный macOS-инструмент для анализа MIDI и создания гармонических альтернатив.

## Как работает интеграция с Logic Pro

Основной сценарий — экспортировать из Logic MIDI-файл проекта или выбранных регионов, открыть его в приложении, создать варианты и перетащить готовый `.mid` из списка вариантов обратно в окно Logic. Приложение анализирует все MIDI-дорожки импортированного файла и сохраняет темп, размер и длину фразы.

MIDI FX на мастер-канале здесь не подходит: мастер-канал Logic передаёт аудио, а MIDI FX устанавливается на MIDI/инструментальную полосу канала. AU MIDI FX получает входящие MIDI-события во время проигрывания и может изменять поток для последующих плагинов на этой полосе. Он не получает доступ к списку регионов или полному содержимому проекта и не может задним числом анализировать все записанные партии. Поэтому приложение не заявляет о такой функции и не устанавливает фиктивный плагин. В будущем отдельный AU MIDI FX может преобразовывать только события, реально поступившие на его вход.

Перетаскивание результата — обычное перетаскивание экспортируемого MIDI-файла из карточки варианта в Logic. Это не live-подключение к проекту.

## Запуск на macOS

Нужен Python 3.10+ с Tk-independent Qt UI dependency PySide6:

```sh
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python -m harmonic_shadow
```

Для сборки переносимого `.app` на macOS:

```sh
python -m pip install -r requirements-build.txt
pyinstaller HarmonicShadow.spec --clean
```

Артефакт появится в `dist/Harmonic Shadow.app`. Сборку нужно запускать на macOS. Приложение работает локально и не использует сеть или облачные модели.

## Быстрый сценарий

1. Экспортируйте MIDI из Logic (`File → Export → All MIDI Tracks…`) или отдельный регион.
2. Перетащите `.mid` в окно приложения или нажмите `Open MIDI`.
3. Просмотрите распознанные аккорды, тональный центр, бас и piano roll. Аккорд можно исправить двойным щелчком.
4. Задайте характер, Darkness, Transformation и кривую напряжения.
5. Нажмите `Generate Variations`; выберите вариант, прослушайте его и перетащите MIDI-файл из карточки в Logic.

Режим `From scratch` доступен как вторичный: выберите тональность и лад, число тактов и характер.

## Алгоритм

Парсер читает Standard MIDI File Type 0 и 1, полифонию, несколько дорожек, tempo map и размер. Анализ использует длительность нот, распределение классов высоты, профили мажор/минор, шаблоны аккордов, басовую ноту, функции и повторяющиеся фрагменты. Детерминированные стратегии связывают заимствования, вторичные доминанты, хроматические медианты и тритоновые замены с типом и уровнем напряжения. Голосоведение выбирается по движению голосов и сохранению общих тонов; варианты ранжируются по голосоведению, связности, трансформации и кривой напряжения.

Текущая версия рассчитана на гармонический слой. Тембр предпрослушивания — локальный встроенный синтезатор, чтобы прослушать ноты без внешних API или банков звуков. MIDI экспортируется отдельными дорожками аккордов и баса.

## Проверка

```sh
python -m unittest discover -s tests -v
```

Тестовые MIDI в тестах создаются в памяти: простая тональная прогрессия, модальная последовательность, хроматические аккорды и отдельная басовая дорожка. Отдельно проверяются MIDI Type 0/1, повторный разбор экспорта и генерация пяти музыкальных вариантов.
