# Harmonic Shadow

Локальный AU MIDI FX для Logic Pro: собирает MIDI-фразы с выбранных дорожек во время проигрывания и предлагает гармонические альтернативы для каждой партии в одном окне.

## Сценарий в Logic Pro

1. Установите AU MIDI FX на каждую MIDI-инструментальную дорожку, которую нужно учитывать. Эффект ставится в слот MIDI FX перед инструментом, не на аудиомастер.
2. Откройте окно любого экземпляра, назовите его партию и нажмите `Start capture`.
3. Запустите Logic с начала нужного фрагмента. Экземпляры объединяют входящие ноты по позиции хоста.
4. Нажмите `Stop & analyze`. Одно окно показывает общий piano roll, тональный центр, распознанные аккорды и список партий.
5. Выберите одну партию или `All captured parts`, задайте настроение и параметры, нажмите `Generate suggestions`.
6. Перетащите строку варианта из окна плагина в аранжировку Logic. Плагин создаёт временный MIDI-файл для системного drag-and-drop; вручную сохранять или искать файл не нужно.

Доступен вторичный режим `Generate from key`: он создаёт гармоническую фразу с выбранной тональностью, ладом и длиной.

## Что видит MIDI FX

AU MIDI FX получает события своей дорожки, проходящие через него во время воспроизведения. Он не сканирует сохранённые регионы и не читает MIDI с аудиомастера. Чтобы собрать несколько партий, поставьте экземпляр на каждую нужную дорожку и проиграйте фрагмент один раз. Дорожки без активного экземпляра в сессию не попадут. Названия партий задаются в плагине, так как стандартный AU MIDI FX не предоставляет надёжный доступ к именам дорожек Logic.

Позиция событий берётся из PPQ-позиции транспортной линии Logic и нужна для совмещения партий. Если хост её не сообщает, окно показывает предупреждение. Реальная работа drag-and-drop и сканирование AU должны быть проверены в установленном Logic Pro на macOS.

## Сборка и установка на Apple Silicon

Нужны macOS 11+, Xcode Command Line Tools и CMake 3.22+. Скрипт собирает arm64 AU и запускает тесты движка:

```sh
bash scripts/install-macos.sh
```

При сборке JUCE 8.0.6 загружается из публичного репозитория JUCE. Сам плагин при работе не обращается к сети и не использует облачные сервисы или языковые модели. После установки откройте Logic Pro Plug-in Manager и выполните повторное сканирование Audio Units, если плагин не появился. Найдите `Harmonic Shadow` в категории MIDI FX.

## Тесты музыкального ядра

```sh
cmake -S . -B build -DHARMONIC_SHADOW_BUILD_PLUGIN=OFF
cmake --build build --parallel
ctest --test-dir build --output-on-failure
```

Примеры проверяют тональную прогрессию, Dorian, хроматическую гармонию и отдельные басовую/аккордовую дорожки. Также проверяются пять вариантов, сохранение ритма баса, изменение гармонического ритма, Horror-напряжение и MIDI Type 1 экспорт.

## Текущий объём

- AUv2 MIDI FX собирает MIDI-события в общей сессии экземпляров и передаёт исходные события без изменений.
- Алгоритм оценивает ладовый центр по нотам и аккордовым корням; использует модальное заимствование, хроматические медианты, вторичные доминанты, тритоновые замены, уменьшённые аккорды и общие тоны.
- Варианты ранжируются по голосоведению, гармонической связности, степени трансформации и напряжению.
- Есть режимы Dark, Melancholic, Tension, Horror, Epic, Mystery, Release и Custom.
- `Horror` поднимает целевой уровень напряжения выше остальных режимов; `Darkness` и кривая задают его развитие.
- Выходной MIDI содержит дорожку темпа/размера и дорожку предложенной партии.
- Метка экземпляра, общая захваченная фраза, параметры и ручные коррекции аккордов записываются в состояние MIDI FX при сохранении проекта Logic.
- Переключатель `Keep bass rhythm` сохраняет атаки и длительности баса, меняя высоты под предложенную гармонию.

Встроенное прослушивание MIDI-варианта пока не реализовано: перетащите вариант на MIDI-регион и прослушайте его инструментом Logic. Сборка AU, проверка Audio Unit Validation, захват из транспорта Logic, сохранение/восстановление сессии и перетаскивание в Arrangement требуют проверки на macOS. Среда разработки этого репозитория — Linux, поэтому здесь проверяется музыкальное ядро и формат MIDI, но не GUI-плагин и хостовый цикл Logic. Подробное состояние и решения см. в [STATUS.md](STATUS.md).
